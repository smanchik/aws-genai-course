# AWS Generative AI for IT Professionals

An interactive, animated 13-chapter course for IT professionals migrating on-prem applications to AWS and enabling them with Generative AI capabilities.

**Start here:** open [`index.html`](index.html) in a browser, or visit the GitHub Pages site if enabled.

## Course structure

| Part | Chapters |
|---|---|
| **I · Orientation** | 1. The GenAI Service Landscape · 2. Amazon Bedrock Deep Dive |
| **II · Core building blocks** | 3. Prompt Engineering · 4. RAG & Knowledge Bases · 5. Agents & Agentic AI |
| **III · Production readiness** | 6. Guardrails & Responsible AI · 7. Amazon Q · 8. GenAI Application Patterns · 9. Security, Privacy & Governance |
| **IV · Operate & apply** | 10. Cost Optimization & Performance · 11. Monitoring, Evaluation & Troubleshooting · 12. Capstone I: Migrate & AI-Enable a Helpdesk App · 13. Capstone II: AIOps — Automated Incident Troubleshooting |

## Features

- Fully static — no build step, no dependencies; every chapter is a self-contained HTML file
- Animated SVG/CSS illustrations and interactive demos in every chapter (token cost calculator, guardrail simulator, agent trace steppers, RAG pipeline animations, and more)
- On-prem analogies throughout, aimed at engineers mid-cloud-migration
- Hands-on lab callouts linking to free official AWS workshops
