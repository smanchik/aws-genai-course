12.3 · Your build

The capstone checklist

If you did the labs, you've already built most of this. Assemble it end to end — in your own account, with sample data standing in for AnyCompany's:

  1. Land the data (Phase 1). Sample "runbooks" and "policies" into S3; a small ticket table in Aurora or DynamoDB. Tag everything for cost allocation (Ch. 10).
  2. Instant win (Phase 2). Q Business over the S3 docs with Identity Center — verify permission-aware answers with two test users (Ch. 7).
  3. Self-service RAG (Phase 3). Knowledge Base + RetrieveAndGenerate behind API Gateway/Lambda with streaming, conversation history in DynamoDB (Ch. 4, 8).
  4. Triage agent (Phase 4). Bedrock Agent or Strands: classify the ticket, query the KB, call a create_ticket Lambda tool; human approval before any write (Ch. 5).
  5. Harden (Phase 5). Guardrail (topics + PII masking + grounding) attached everywhere, model-scoped IAM, guardrail-mandatory deny condition, VPC endpoint, invocation logging (Ch. 6, 9).
  6. Operate (Phase 6). Golden test set in a Bedrock Evaluation job, quality dashboard, p95 TTFT + token + intervention alarms, cost review against your Ch. 10 model.
  7. Tell the story. One architecture diagram + three numbers (deflection rate, cost per conversation, time-to-answer). That's the deck that funds the next one.
